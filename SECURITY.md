# Security policy

Non aprire issue pubbliche con segreti, documenti o dati personali. Segnalare privatamente tramite GitHub Security Advisories. Non allegare file reali.

In caso di esposizione: revocare e ruotare subito le credenziali, disabilitare gli accessi, rimuovere artifact e cache, valutare la riscrittura completa della cronologia e avviare la procedura incidenti. La cancellazione di un commit non elimina le copie già diffuse.

Il prototipo usa esclusivamente dati sintetici. Prima di dati reali sono obbligatorie autorizzazione istituzionale e valutazione DPO/IT.
