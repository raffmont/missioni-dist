# Contribuire

- Usare solo dati inventati e indirizzi `example.org`.
- Non caricare allegati, screenshot, log o dump reali, neppure nelle issue.
- Eseguire `pre-commit run --all-files` e l'intera suite prima di una PR.
- Le PR da fork non ricevono segreti. I workflow hanno permessi minimi.
- Ogni modifica UI richiede test axe e checklist tastiera/screen reader; ogni endpoint richiede un test di autorizzazione per-oggetto.
